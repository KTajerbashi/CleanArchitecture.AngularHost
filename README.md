# .NET + Angular — Integrated SPA Template

A Clean Architecture starter template where an Angular SPA is built and served
directly from ASP.NET Core on a single port — a common enterprise deployment
pattern that avoids CORS and simplifies hosting.

## What this demonstrates
- Clean Architecture layering (Domain / Application / Infrastructure / API)
- Serving a compiled Angular app through ASP.NET Core middleware
- SQL Server integration via EF Core
- Single-port dev & production setup (no CORS configuration needed)

## Note
This is an infrastructure/architecture template — it intentionally has no
business domain logic. Use it as a starting point for new full-stack .NET +
Angular projects. For a full business-domain implementation with DDD/CQRS,
see [NovaCommerce](link).

## Tech Stack
| Layer | Technology |
|---|---|
| Backend | .NET, ASP.NET Core |
| Frontend | Angular |
